# Two-Stage Sporadic Cystitis Detection

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![HuggingFace](https://img.shields.io/badge/🤗%20HuggingFace-Model-yellow)](https://huggingface.co/jibmaird/sporadic-cystitis-two-stage)
[![Python 3.11+](https://img.shields.io/badge/python-3.11%2B-blue.svg)](https://www.python.org/)

Code accompanying the paper *"Two-Stage Decomposition of Sporadic Cystitis
Detection in Veterinary Clinical Text"* (paper link: TBD once published).

The paper argues that detecting Sporadic Cystitis (SC) in veterinary clinical
notes decomposes into two separable sub-problems of very different
difficulty:

- **Stage 1 -- UTI identification (topic recognition):** is this note about a
  urinary tract disorder at all? Solved near-perfectly by a frozen,
  general-purpose model (VetBERTDx) with no SC-specific training
  (AUC-ROC = 0.984).
- **Stage 2 -- SC vs. Other-UTD (within-topic discrimination):** is the
  urinary case Sporadic Cystitis specifically, or a clinically similar
  condition (FIC, FLUTD, urolithiasis, recurrent cystitis, urethral
  obstruction)? Tractable in isolation (CV F1 = 0.860), but unstable when
  folded into a single end-to-end classifier over the full, highly imbalanced
  population.

Explicitly gating Stage 2 behind Stage 1 removes most of that instability
without retraining anything.

**No real patient data is included in this repository.** The paper's dataset
is private veterinary clinical data and cannot be redistributed. Everything
here runs end-to-end on a small, fabricated synthetic dataset generated by
`tools/generate_synthetic_data.py` -- see
[`data/ann04062026/README.md`](data/ann04062026/README.md). Point the same
scripts at your own data (same column schema) to reproduce real results.

## Repository layout

```
src/models/                    Frozen VetBERTDx wrapper + hybrid feature extractor
                                (used by the Stage-1 gate and Stage-2 ML baselines)

scripts/data_preparation/      Raw annotation CSVs -> (text, Label) training files
scripts/training/              The 4 architecture families trained in the paper:
                                  - traditional ML (RF/LR/SVM x 4 feature sets)
                                  - VetBERTBinary (standard fine-tuning)
                                  - Dual-Head fusion (4 strategies)
                                  - Multi-Knowledge fusion (4 strategies)
scripts/evaluation/            Stage-1 gate, Stage-2 cross-validation, two-stage
                                gating/evaluation, bootstrap CIs, McNemar tests,
                                error analysis
scripts/testing/               Architecture smoke tests (no data required)

tools/generate_synthetic_data.py   Fabricates the 3 raw CSVs the pipeline expects
data/ann04062026/                  Synthetic data lives here (see its README)
huggingface/                       Model card + upload script for the Hugging Face
                                    Hub release (see "Pretrained models" below)
```

Every script under `scripts/` is a thin wrapper that can be run directly with
`python scripts/.../some_script.py --help`; none require installing this repo
as a package.

## Installation

```bash
conda env create -f environment.yml && conda activate sc-two-stage
# or:
pip install -r requirements.txt
```

Requires Python 3.11+. All models are loaded from the Hugging Face Hub at
runtime (`havocy28/VetBERTDx`), so an internet connection is needed the first
time each script runs (weights are then cached locally).

### Running without Weights & Biases

The three fine-tuning scripts (`fine_tune_on_cystitis_refined_binary.py`,
`fine_tune_vetbert_dual_head.py`, `fine_tune_multiknowledge_endtoend.py`) log
to [wandb](https://wandb.ai) during training. If you don't have (or don't
want) a wandb account, run with:

```bash
WANDB_MODE=disabled python scripts/training/fine_tune_vetbert_dual_head.py ...
```

Model checkpoints are still saved locally regardless of wandb mode.

## Quickstart (synthetic data)

```bash
# 1. Generate fabricated raw data (~200/100/100 train/dev/test rows)
python tools/generate_synthetic_data.py --seed 0

# 2. Derive the two label schemes used throughout the paper:
#    - binary_SC:  Sporadic Cystitis vs. Other (single-stage baselines, §4.3)
#    - binary:     Cystitis Sporadic vs. UTD Other, is_utd records only (Stage 2, §4.2)
python scripts/data_preparation/prepare_ann04062026_SC_data.py
python scripts/data_preparation/prepare_ann04062026_data.py

# 3. Stage 1 -- cache frozen VetBERTDx P(urinary tract disorder) for dev+test
python scripts/evaluation/sc_cascade_step1_extract_utd_probs.py

# 4. Stage 2 -- extract frozen features, then run the 5-fold CV suite
python scripts/evaluation/sc_stage2_extract_features.py
python scripts/evaluation/sc_stage2_ml_cv.py
python scripts/evaluation/sc_stage2_vetbert_cv.py   # fine-tunes per fold; no checkpoint is saved (see Limitations)

# 5. A single-stage baseline, end to end (traditional ML, all 12 configs)
python scripts/training/train_evaluate_ml_ann04062026.py \
  --train_file data/ann04062026/processed/train_binary_SC.csv \
  --dev_file   data/ann04062026/processed/dev_binary_SC.csv \
  --test_file  data/ann04062026/processed/test_binary_SC.csv

# 6. A single-stage DL baseline (example: Multi-Knowledge, Gated fusion)
python scripts/training/fine_tune_multiknowledge_endtoend.py \
  --fusion_strategy gated \
  --train_file data/ann04062026/processed/train_binary_SC.csv \
  --val_file   data/ann04062026/processed/dev_binary_SC.csv \
  --checkpoint_name demo_gated.pt --epochs 5

python scripts/evaluation/evaluate_multiknowledge_ann04062026_SC.py \
  --model_path checkpoints/demo_gated.pt --fusion_strategy gated \
  --test_file data/ann04062026/processed/test_binary_SC.csv

# 7. Two-stage evaluation, stats
python scripts/evaluation/sc_bootstrap_ci.py
python scripts/evaluation/sc_mcnemar_test.py
```

`fine_tune_vetbert_dual_head.py` and `fine_tune_multiknowledge_endtoend.py`
both accept `--fusion_strategy` (`concatenation|weighted|cross_attention|
multi_task` for Dual-Head; `attention|gated|cross_modal|hierarchical` for
Multi-Knowledge), `--seed`, `--epochs`, and `--checkpoint_name` -- the paper's
multi-seed runs (§5.4) are produced by calling the same script three times
with different `--seed`/`--checkpoint_name` values, not by any code branch.

Remember: **scores from synthetic data are meaningless** -- the synthetic
classes use deliberately distinct vocabulary and will look trivially
separable. They confirm the code runs, nothing more.

## Which script maps to which paper section

| Paper section | Script(s) |
|---|---|
| §3.1 Data | `scripts/data_preparation/prepare_ann04062026{_SC,}_data.py` |
| §4.1 Stage-1 gate | `scripts/evaluation/sc_cascade_step1_extract_utd_probs.py`, `sc_cascade_step1_utd_gate_leakfree.py` |
| §4.2 Stage-2 CV | `scripts/evaluation/sc_stage2_extract_features.py`, `sc_stage2_ml_cv.py`, `sc_stage2_vetbert_cv.py` |
| §4.3 Single-stage baselines | `scripts/training/train_evaluate_ml_ann04062026.py`, `fine_tune_on_cystitis_refined_binary.py`, `fine_tune_vetbert_dual_head.py`, `fine_tune_multiknowledge_endtoend.py`, and the matching `scripts/evaluation/evaluate_*_ann04062026_SC.py` |
| §4.4 Two-stage pipeline | `scripts/evaluation/sc_cascade_gate_all_seeds.py`, `sc_two_stage_evaluation.py` |
| §4.5 Stats | `scripts/evaluation/sc_bootstrap_ci.py`, `sc_mcnemar_test.py` |
| §6.4 Error analysis | `scripts/evaluation/sc_error_analysis.py`, `sc_error_analysis_pipeline.py`, `sc_error_overlap_gated.py`, `sc_error_review_spreadsheet{,_v2}.py` |

A handful of older/exploratory scripts from the original research codebase
(alternative architectures never reported in the paper, hyperparameter-sweep
tooling, dataset versions whose source files no longer exist) were left out
of this release as not relevant to reproducing the paper's results.

## Pretrained models

Checkpoints for the paper's four best-performing single-stage architectures
(the ones fed into the two-stage pipeline evaluation, §5.4) are published at
[huggingface.co/jibmaird/sporadic-cystitis-two-stage](https://huggingface.co/jibmaird/sporadic-cystitis-two-stage):
Multi-Knowledge Gated (seed 43), Multi-Knowledge Cross-Modal (seed 42),
Dual-Head Cross-Attention (seed 43), and Dual-Head Weighted (seed 43). See
[`huggingface/README.md`](huggingface/README.md) for the model card, file
sizes, and a loading snippet.

Note: the paper's Stage-2-only VetBERT result (§4.2, §5.2) comes from 5-fold
cross-validation, where each fold's model is trained purely to compute
out-of-fold predictions and discarded -- there is currently no single
checkpoint corresponding to that result (this matches the paper's own
Limitation #3: a purpose-built Stage-2 classifier has not yet been built).
